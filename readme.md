💻 Desarrollada con HTML5, CSS3 y JavaScript Vanilla, orientada a la representación del aprendizaje obtenido del curso.

⚙️Se usó type module, async, fetch, http, un archivo json en (productos.json) y se renderizaron las tarjetas desde js. 

⌛ Se incorporó como detalle visual, sweetalert2 para customizar mensajes descriptivos
